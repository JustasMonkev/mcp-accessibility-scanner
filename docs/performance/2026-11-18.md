# MCP tool latency on Chromium 159

The longest call in the original suite was a 12-stop keyboard audit at 7.48 s. Its default 500 ms settle delay plus up to 100 ms watching for scheduled activity accounts for about 7.2 s on this quiet page. The new per-audit `settleAfterKeyMs: 0` option took 125 ms on the same fixture. The previous server could already run it in 131 ms with the server-wide `--timeout-settle 0` setting. The default, per-audit and server-wide settings produced identical saved stops, issue arrays and skip-link results on this static fixture. Sites that move focus from timers or animations can require the default delay.

Console output now finds base64 payload boundaries in a single native regular-expression search. Only shortened console strings are cached, keyed by the original event. When a navigation snapshot has already rendered a log, a later console listing reuses the compact text.

## Reproduction

Baseline `c2c7f1ebfb25`. Both builds used Linux x64, AMD EPYC 9V74 80-Core Processor, Node v24.22.3, Playwright 1.65.1, Chromium headless shell 159.0.8154.6 and Axe 4.14.0. All pages were local fixtures. The console stress fixture emits four 1 MiB base64 payloads and verifies every retained message suffix. Its seven measured calls follow two warmups. The `first read` fixture emits logs during a plain input fill. The `after snapshot` fixture emits them during navigation. Only the console listing itself is timed.

Build both checkouts and use the candidate benchmark driver against each server. For the 45-tool runs, use the same candidate direct harness in each checkout. Its call logs include the elapsed time and tool error status.

```sh
npm ci && npm run build
node bench/mcp-bench.mjs --server "$BASE/cli.js" --lib "$BASE/lib" --executable-path "$CHROMIUM" --iterations 3 --out before.json
node bench/mcp-bench.mjs --executable-path "$CHROMIUM" --iterations 3 --out after.json
node bench/mcp-bench.mjs --only browser_console --executable-path "$CHROMIUM" --warmups 2 --iterations 7
PLAYWRIGHT_MCP_BROWSER=chromium PLAYWRIGHT_MCP_EXECUTABLE_PATH="$CHROMIUM" node .codex/run-mcp-direct-harness.mjs --include-optional --include-install
node .codex/run-mcp-direct-harness.mjs --only browser_connect
```
